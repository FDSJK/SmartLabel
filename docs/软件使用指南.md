# 灵标（Ling Label）软件使用指南

> 适用版本：当前开发版（标注编辑器阶段）
> 面向对象：标注员（annotator）与管理员（admin）

本指南介绍标注编辑器中的交互操作，重点覆盖：批次与图像导入、绘制、选中、增添/裁剪、撤销重做、标签确认、保存等日常标注流程。

---

## 1. 快速开始

1. 在浏览器打开前端地址（默认 `http://localhost:5173`），使用账号登录。
   - 默认管理员：`admin` / `admin`（首次启动后端时自动创建）。
2. 管理员先在「用户管理」里创建标注员账号（只能建标注员，无法再建管理员）。
3. 每个用户登录后，先在顶栏「设置」页配置**自己的工作目录**（数据根目录）。
4. 进入「标注」主页，在左侧选择**批次**，再点击一张图像打开。

> 系统只有一个 `admin` 管理员账号；admin 只能新建/管理**标注员**，不能新建管理员。

打开图像时，系统会自动获取**编辑锁**；若该图像正被他人编辑，则以**只读**方式打开，并在列表中显示锁图标 🔒 与持锁人。

## 2. 界面布局

```
┌──────────────────────────────────────────────────────┐
│ 顶栏：灵标 · 标注 / 统计 / 设置 / 用户管理 / 标签管理 │
├──────────┬──────────────────────────┬───────────────┤
│ 左栏     │          画布             │  右栏          │
│ 批次选择 │                          │  工具          │
│ 扫描/上传│  [‹ 2/6 › ↩ ↪ ▣ 已保存]  │  标签状态/标注  │
│ 导出标注 │     ↑ 悬浮控制条          │  （标签页）    │
│ 图像列表 │                          │               │
└──────────┴──────────────────────────┴───────────────┘
```

- 「设置」对所有用户可见；「用户管理 / 标签管理」仅管理员可见。
- **左栏**：批次下拉 + 扫描/上传按钮 + 「⇩ 导出标注」按钮，下方是图像列表（详见 §3）。
- **中间**：标注画布。左上角有一个悬浮控制条（上一张/下一张、撤销/重做、填充切换、缩放比例、标注数量、保存状态）。
- **右栏**：上半部分是工具按钮，下半部分是「标签状态 / 标注」两个标签页。
- 左右两栏顶部各有 `‹` / `›` 按钮，点击可**折叠/展开**，让画布全屏。

## 3. 批次管理与图像导入

左栏负责批次与图像的管理，操作按钮位于批次下拉框下方。

**每个用户只能看到自己工作目录下的批次，看不到其他用户的批次**；扫描 / 上传 / 删除批次等操作所有登录用户都可以做，但只作用于自己的数据。

### 3.1 选择批次

- 在「-- 选择批次 --」下拉框中，每个批次显示为 `批次名 (已完成数/总数)`。
- 选择批次后，下方图像列表自动加载该批次的图像。

### 3.2 扫描导入（扫描按钮）

- 点击「扫描」会扫描工作目录下的批次文件夹，自动识别并创建批次。
- 完成后弹出提示：`扫描完成：新增 X，跳过 Y`。
  - 新增：本次新识别出的批次。
  - 跳过：已存在、无需重复创建的批次。

### 3.3 上传图像（新建上传）

- 当**未选择批次**时，按钮显示「新建上传」。
- 点击后弹出输入框要求填写**批次名称**，然后选择图像文件。
- 系统会先创建该批次，再把所选图像上传进去，并自动选中这个新批次。

### 3.4 补充上传

- 当**已选择批次**时，按钮显示「补充上传」。
- 点击后选择图像文件，图像会追加到当前选中的批次中。

> 支持的文件格式：PNG、JPEG、TIFF；可一次多选。

### 3.5 删除批次

- 所有登录用户可删除**自己的**批次（需先选中一个批次）。
- 点击后需二次确认：**未标注的批次会被删除，已标注的批次无法删除**。

### 3.6 图像列表

- 每行显示一张图像，含状态图标、文件名，以及可能的锁标记。
- 状态图标：

| 图标 | 状态 | 含义 |
| --- | --- | --- |
| ○ | 未开始 | pending |
| ◐ | 进行中 | in_progress |
| ● | 已完成 | done |

- 若图像正被他人编辑，行尾显示 🔒，悬停可见持锁人。
- 点击某张图像即打开进入标注（打开时自动获取编辑锁）。

### 3.7 切换图像（上一张 / 下一张）

- 悬浮控制条**最左侧**有 `‹`（上一张）和 `›`（下一张）按钮，中间显示 `当前位置/总数`（如 `2/6`）。
- 也可以用键盘 **`←`** / **`→`** 切换上一张 / 下一张。
- 按**当前批次图像列表的顺序**切换；在第一张/最后一张时对应按钮置灰，不会越界。
- 正在绘制多边形/自由曲线时，按 `←`/`→` 不会切换图像（防止误触丢失未完成的标注）。
- 切换时自动释放上一张的编辑锁、获取下一张的锁。

### 3.8 我的工作目录

- 每个用户在「设置」页填的工作目录是**服务器上的、属于自己的目录**；上传/扫描的批次数据都落在该目录的 `batches/` 子目录下，仅本人可见。
- 未设置时回退到旧的全局目录。

## 4. 工具说明

工具按钮位于**右栏**顶部，快捷键见括号：

| 工具 | 快捷键 | 用途 |
| --- | --- | --- |
| 多边形 | P | 单击逐点布点，绘制多边形 |
| 自由绘制 | F | 按住拖动绘制自由曲线 |
| 选择 | S | 双击选中、拖动顶点/整体、删除 |
| + 增添 | A | 在选中目标上增加区域（并集） |
| - 裁剪 | X | 从选中目标上裁掉区域（差集） |

> 数字键 `1–9` 可快速切换当前标签（按启用标签顺序），再按同一数字取消选中标签。

## 5. 绘制标注

**开始前**：先在右栏「标签状态」页点击标签的色块或名称，选中一个标签。未选中标签时无法绘制。

### 5.1 多边形工具（P）

1. 左键**单击**放下第一个顶点。
2. 移动鼠标，会显示到光标的预览虚线。
3. 继续单击放下更多顶点。
4. **右键**闭合：首尾相连，生成闭合多边形。

绘制中：
- `Ctrl+Z` 退一个顶点；
- `Esc` 取消整条折线。

### 5.2 自由绘制工具（F）

1. 左键**按住拖动**，沿轨迹连续采样（每约 5px 采一点）。
2. **松开左键**：曲线暂存为未闭合折线。
3. **右键**闭合：首尾相连，生成闭合多边形。

---

## 6. 选择与编辑

选择工具（S）用于选中与修改已有标注。

### 6.1 双击选中

- 在**选择（S）、增添（A）、裁剪（X）** 三个状态下都可以**双击**选中目标。
- 双击某个标注 → **始终选中**它（不会因重复双击而取消）。
- 双击空白区域 → 取消选中。
- 选中后，高亮轮廓、光晕和顶点圆点**使用该标注自己的标签颜色**，而不是统一颜色。

### 6.2 拖动顶点 / 平移形状

- 选中后，**拖动顶点**：移动单个顶点。
- **拖动形状内部**：整体平移该形状。

### 6.3 删除

- 选中后按 `Delete` 或 `Backspace`；
- 或点击选中形状上方出现的红色 **×** 按钮；
- 或在右栏「标注」列表中点击某项的 × 删除。

---

## 7. 增添与裁剪

这两个工具都作用于**当前选中的目标形状**。

1. 先双击选中目标形状（见 6.1）。
2. 切到「+ 增添」（A）或「- 裁剪」（X）。
3. 在画布上**自由绘制**一块区域（同自由绘制一样按住拖动）。
4. **松开鼠标**立即应用：
   - **增添**：该区域与目标取**并集**，形状扩大。
   - **裁剪**：从目标中减去该区域，可能把形状切成多块。
5. 操作完成后**选中态仍停留在目标形状**（裁剪成多块时停留在面积最大的那块）。

---

## 8. 撤销 / 重做

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl/Cmd + Z` | 撤销（绘制中退一个顶点；否则撤销上一步操作） |
| `Ctrl/Cmd + Shift + Z` | 重做 |

悬浮控制条中也有对应的 ↩ / ↪ 按钮，悬停可看到文字提示。

---

## 9. 标签状态确认（防漏标）

每个标签对当前图像有三种确认状态，用于防止漏标：

| 图标 | 状态 | 含义 |
| --- | --- | --- |
| ✓ 存在 | present | 该标签存在，已标注 |
| ✗ 不存在 | absent | 该标签不存在 |
| ○ 待定 | pending | 尚未确认 |

- 在右栏「标签状态」标签页点击右侧的状态按钮即可切换。
- 所有标签都确认为 present 或 absent 后，图像自动标记为**已完成**。

---

## 10. 标注列表（绑定标签）

- 右栏「标注」标签页显示当前图像的标注列表。
- **选中某个标签后，标注列表只显示该标签的标注**（编号在该标签内重新排序）。
- 未选中标签时，显示全部标注。
- 点击列表项可选中对应标注（自动切到选择模式）；点击项右侧 × 可删除。

---

## 11. 保存与锁

- **自动保存**：每次增删改或标签确认后约 300ms 自动保存到工作目录。
- **保存状态**（悬浮控制条最右侧）：`已保存`（绿点）/ `保存中…` / `未保存`（橙）/ `离线`（红）。
- **编辑锁**：
  - 打开图像自动获取锁，每 60 秒心跳续期。
  - 切换图像、离开页面或关闭浏览器时自动释放锁。
  - 若他人正持有锁，则以只读方式打开，不能编辑。

## 12. 导出标注

在左栏图像列表上方的「⇩ 导出标注」按钮打开导出对话框，把标注结果导出为文件快照。

### 12.1 选择范围

| 范围 | 说明 |
| --- | --- |
| 当前图像 | 只导出当前打开的这一张（需已打开图像） |
| 当前批次 | 导出当前选中批次的全部图像（需已选中批次） |
| 全部批次 | 导出所有批次的所有图像 |

### 12.2 选择格式

| 格式 | 产物 |
| --- | --- |
| PNG 二值 mask | `masks/<标签名>/<原图名>.png`，每图每标签一张（黑白 0/255） |
| COCO | `coco/annotations.json`，整个范围一个文件（含 Polygon 与 RLE，保留孔洞） |
| labelme | `labelme/<原图名>.json`，每图一个文件（孔洞标为 `_background_`） |

### 12.3 未确认标签闸门

- 范围内存在**未确认（待定）标签**时，先弹出警告清单（按图列出）。
- 点「忽略并继续导出」则跳过这些未确认标签（不生成对应 mask / COCO 标注）；或点「返回」先回去补齐。
- 完成后会提示「跳过未确认标签（涉及 N 张图）」。

### 12.4 导出结果

- 成功后显示导出目录与统计：图像数 / 标注数 / mask 数。
- 文件写到 `<工作目录>/export/<时间戳>-<范围>/` 下，按所选格式生成 `coco/`、`labelme/`、`masks/` 子目录。

## 13. 数据看板

点击顶栏「统计」进入数据看板页，查看各标签的标注进度。

### 13.1 范围与总数

- 顶部「批次」下拉框切换统计范围：**全部数据**或某个批次。
- 旁边显示**数据总数**（当前范围的图像数）。

### 13.2 统计表与图表

- **左侧统计表**：每行一个标签，三列 **阳性 / 阴性 / 未确认**，每格显示 `计数 (百分比)`。
  - **阳性** = 已确认「存在」的图像数
  - **阴性** = 已确认「不存在」的图像数
  - **未确认** = 「待定」或尚未标注此标签的图像数（橙色高亮，提示漏标）
- **右侧堆叠横向条形图**：每标签一横条，按 阳性（绿）/ 阴性（灰）/ 未确认（橙）分段，悬停可见具体数值与图例。

### 13.3 标签筛选

- **搜索框**：输入关键词按标签名模糊过滤。
- **「标签筛选」按钮**：打开复选框下拉，勾选要显示的标签（支持「全选 / 清空」）。
- 搜索与勾选会**同时**作用于表格和图表。

### 13.4 统计口径

- 百分比 = 该计数 ÷ 数据总数 × 100%，保留 1 位小数。
- 「未确认」= 状态为「待定」或该图未标注此标签。
- 数据在每次打开页面或切换范围时实时计算，反映最新标注结果。

## 15. 常见问题

**Q：为什么画不了？**
未选中标签。先在右栏「标签状态」页选中一个标签。

**Q：双击选中后轮廓是蓝色，不是目标颜色？**
请刷新页面（`Cmd/Ctrl + Shift + R`）后重试；选中高亮已改为跟随标签自身颜色。

**Q：增添/裁剪后选中目标变了？**
确保已双击选中目标再操作；操作后选中态应停留在目标形状。

**Q：自由绘制和增添/裁剪的完成方式为什么不一样？**
自由绘制（F）是「松开暂存、右键闭合」；增添（A）/裁剪（X）是「松开立即应用」。

**Q：图像打不开 / 只读？**
可能被他人锁定（列表有 🔒 与持锁人），或工作目录未配置。

**Q：扫描没有识别到批次？**
确认工作目录已正确配置，且目录下存在符合命名规范的批次文件夹（每批次一个文件夹）。
